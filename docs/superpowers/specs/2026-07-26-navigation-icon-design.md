# 导航图标视觉统一设计

## 目标

使用确认后的 `resty-icon.png` 作为应用品牌图标，并修正 macOS 菜单栏中的违和感。

## 方案

- 应用窗口、Dock 和安装包图标采用新插画，保留其粉色山水与眼睛的品牌特征。
- 菜单栏托盘图标采用由同一图形提炼出的单色模板版本；macOS 根据菜单栏背景自动着色，不再显示彩色圆角方块。
- 保持现有的浅色和深色主题托盘切换路径，以及其他托盘行为不变。

## 影响范围

- 仅替换 `src-tauri/icons` 下的应用与托盘图标资源，并调整 Rust 代码引用到专用托盘模板资源。
- 不改变导航、窗口、计时或设置的功能接口。

## 验证

- 检查生成资源的尺寸与透明通道。
- 运行前端构建和 `cargo check`。
